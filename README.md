## 💻 BUILT-IN CONSOLE — `TILDE → CHEATS → SPAWN`

Silica includes a native developer console that grants access to cheats, freecam, and a full spawn menu—no third-party tools required [citation:11].

- **Access** — Press the `~` key (below Escape) to open the console. Type `cheats` to enable cheat mode [citation:11]
- **Load a Sandbox Map** — Type `Map riftbasin mp_sandbox` (or another map name like Badlands, CombatDome, GreatErg, MonumentValley, NarakaCity) [citation:11]
- **Freecam** — Press **F** to toggle free-fly camera [citation:11]
- **Spawn Menu** — Press **Backspace** to open. Use `-` and `=` to cycle, `[` and `]` to switch teams, and number keys to spawn units [citation:11]
- **Pause** — Press Pause Break [citation:11]
- **Hide HUD** — Press **G** multiple times to cycle through UI layers [citation:11]
- **Time of Day** — Hold `+` or `-` to adjust [citation:11]
- **Disable AI** — Type `ai` in console to stop units from wandering during scene setup [citation:11]
- **Disable Damage** — Type `damage` to stop units attacking each other [citation:11]
